# 🛍️ Clothing Store Backend

A **Spring Boot** backend for an online clothing store.  
This handles authentication, product management, orders, payments, and admin control.

---

## 🚀 Features

### 👤 User
- Register & Login (JWT Authentication)
- Browse Products
- Add to Cart
- Place Orders & Make Payments
- Track Orders
- View Order History

### 🧑‍🔧 Admin
- Manage Products
- Manage Users
- View Orders
- Generate Reports

---

## 🛠️ Tech Stack
- **Spring Boot**
- **Spring Security (JWT)**
- **Hibernate / JPA**
- **MySQL**
- **Maven**
